# BioFig Studio

面向 AI for Biology 的科研绘图项目：从精选论文图中提炼视觉表达与科学叙事方法，建立可复用的绘图 Skill，并通过实际成图与反馈持续改进。

## 项目方向

- 整理用户精选的 Fig.1 和其他科研图参考，记录来源与偏好。
- 分析科学叙事、布局、配色、图形语言和信息层级。
- 将参考分析与绘图流程整理为可调用的 Skill。
- 基于新的研究内容绘图，保留可编辑源文件并积累修改反馈。

当前阶段：已开始积累参考图与偏好分析，尚未建立绘图 Skill。

- [001 · SMRTnet Fig.1](references/smrtnet-fig1/analysis.md)：清晰的整体叙事、协调的配色、简化而清爽的模型架构。原始 PDF 与截图保存在本地，分析记录参与远程同步。
- [002 · IDPFold2 Fig.1](references/idpfold2-fig1/analysis.md)：用户选入的第二张参考；分析其问题、数据、架构与机制证据的组织，以及与第一张的异同。具体局部偏好尚未确认。
